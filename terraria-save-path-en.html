Frequently Asked Questions & Troubleshooting
1. Can't find the numeric XD ID folder? (Or no numeric folder in Global edition?)
• XD Edition (TapTap): You must launch the game, log into your account, and in the save interface, download your cloud save to local (or create a new local character/world) to generate the numeric ID folder.
• Global Edition: By design, it DOES NOT have a numeric ID folder! Open the game folder and you will directly see Players and Worlds.
2. Game crashes or black screen after replacing patch files?
100% caused by a version mismatch between the patch and the game (e.g., game was updated but the patch is for an older version). Please verify the game version supported by the patch, or reinstall the game to restore clean files.
3. Placed save files but cannot see them in-game?
Check three points: ① Never place files in the OldSaves folder; ② Worlds (.wld) must go into Worlds/world, Characters (.plr) into Players/player; ③ Completely swipe away the game from recent apps and restart it.
4. Connected phone to PC via USB, but Android/data is empty?
Since Android 11, the OS blocks computer access to Android/data, so seeing an empty folder is normal. Copy files into your phone's Download folder first, then use a phone file manager (like MT Manager) to move them into the game folder. If data is inaccessible, grant permission via Shizuku.
5. Connected iPhone to PC, but Terraria doesn't show in Finder / iTunes?
Unlock your iPhone and tap Trust on the prompt. On macOS, select your device in Finder and click the Files tab. On Windows, install iTunes or Apple Devices app and open File Sharing. Only apps supporting document storage will be listed.
6. How to identify save files by extension?
• .wld = World save (place in Worlds / world)
• .plr = Character save (place in Players / player)
• .bak / .bak2 = Automatic backups (delete .bak extension to use as a live save)
• global-metadata.dat = Core engine patch (Android only)

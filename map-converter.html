核心原理与常见问题
1. 什么是地图签名？为什么要转换？
泰拉瑞亚官方国际服与心动代理的国服，在地图文件（.wld）前 64 字节中使用不同的标识字符串标记发行版本。
• 国际服 (Steam/GOG/移动版) 标识为：relogic
• 国服 (心动代理版) 标识为：xindong
如果签名不匹配，游戏在载入地图时会提示“无法加载地图”或在选图列表中不显示。
2. 转换会损坏地图里的建筑、箱子或 NPC 吗？
完全不会！ 本程序严格按照二进制流切片原理，仅对文件头内匹配到的 7 个 ASCII 字节做等长替换（relogic ⇄ xindong），其余数十MB至数百MB的地形、方块、电路与实体数据 100% 保持完全一致。
3. 为什么转换速度这么快？
由于采用了浏览器底层的 File.slice() 技术，它只是在操作系统层面创建虚拟数据引用指针，在保存瞬间才拼合输出，因此无需把几百兆的数据解压或载入内存，即使在手机浏览器上也是毫秒级完成。
4. 如何部署到 GitHub Pages？
只需在 GitHub 创建公开仓库，将本页面的 index.html 提交至根目录，然后在仓库 Settings → Pages 中将来源分支选为 main / root 保存，等待 1 分钟即可生成免费永久在线网址。

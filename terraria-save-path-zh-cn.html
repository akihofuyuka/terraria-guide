常见报错与疑难排查
1. 找不到一串数字的心动ID文件夹？（或国际版没有数字文件夹？）
• 心动版：必须先上游戏登录账号，在存档界面把云存档下载到本地（或新建一个本地角色/地图），才会生成数字 ID 文件夹。
• 国际版：本身就没有数字 ID 文件夹！点进游戏目录后直接就是 Players 和 Worlds。
2. 覆盖补丁后打开游戏闪退 / 黑屏？
100% 是补丁版本与当前游戏版本号不一致（例如游戏更新了但补丁还是老版本）。请确认补丁适配的最新版本号，或卸载重装游戏恢复原文件。
3. 放了存档但进游戏看不到？
检查三点：① 没有误放进 OldSaves 文件夹；② 地图（.wld）必须放 Worlds/world，人物（.plr）必须放 Players/player；③ 彻底划掉游戏后台再重进。
4. 数据线连上电脑，Android/data 里是空的？
安卓 11 起系统会挡住电脑对 Android/data 的访问，看到空文件夹是正常的。把文件先复制到手机 Download 文件夹，再用手机上的文件管理器移进游戏目录；文件管理器进不去 data 的话，按权限检测那一步用 Shizuku 授权。
5. iPhone 连电脑后，访达 / iTunes 里没有泰拉瑞亚？
先解锁手机并在弹窗里点信任；macOS 在访达里选设备后切到文件标签，Windows 需要装 iTunes 或「Apple 设备」App 并打开文件共享。列表里只显示支持文档管理的 App。
6. 如何通过后缀区分存档文件？
• .wld = 地图存档（放 Worlds / world）
• .plr = 人物存档（放 Players / player）
• .bak / .bak2 = 自动备份（删掉 .bak 后缀即可当正式存档）
• global-metadata.dat = 游戏底层补丁（仅安卓可用）
